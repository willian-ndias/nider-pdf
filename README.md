# Nider PDF

Leitor e editor de PDF para Windows, com português do Brasil. Versão alfa, em teste.

**Baseado no [PdfCraft](https://github.com/storytold/pdfcraft)**, de Brandon Thomas e da equipe ArtCraft
(licença MIT OU Apache-2.0). Este projeto é uma cópia modificada: nome, ícone, cores da marca Nider e
instalador. Os avisos de licença originais (`LICENSE-APACHE`, `LICENSE-MIT`, `NOTICE`, `ATTRIBUTION.md`) foram mantidos.

## Instalar

Baixe `nider-pdf-setup-…exe` na página de [Releases](https://github.com/willian-ndias/nider-pdf/releases).
Se o Windows avisar que o aplicativo não é reconhecido, clique em **Mais informações** e depois em
**Executar assim mesmo** (o instalador ainda não tem assinatura digital).
